# Dev

1. Install and run
```shell
npm install
npx tauri dev
```

2. Sending via dcmtk's storescu locally
```
storescu 0.0.0.0 8080 --scan-directories /path/to/files
```

# Build

1. Build the UI

```
$ npm run build
```

2. Run Tauri locally

```
$ next dev
```

3. Or, build the app

```
npm install
npm run tauri dev
```
